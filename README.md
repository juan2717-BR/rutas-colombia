# Sistema de Rutas y Conexiones entre Ciudades de Colombia

## Integrante
- Juan Esteban Benito Bernal

## Objetivo
Crear la base de un proyecto en C++ relacionado con las rutas y conexiones entre ciudades de Colombia. En esta primera entrega se configura el repositorio, se publica el programa inicial y se registra una segunda versión que muestra la ciudad de origen del integrante.

## Lenguaje utilizado
C++

## Archivo principal
- `main.cpp`: programa inicial del proyecto.

## Versiones
1. **Inicio del proyecto:** muestra un mensaje de bienvenida al sistema de rutas de Colombia.
2. **Actualización:** incluye la ciudad de origen del integrante: Villavicencio, Meta.

## Herramientas
- Git para el control de versiones.
- GitHub para alojar y compartir el repositorio.
